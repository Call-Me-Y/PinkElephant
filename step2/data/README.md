# 数据划分与来源

现阶段开发数据只读引用 `../../step1/data/pilot.jsonl`：24任务、48个历史变体，已经看过多轮结果。
不能将它命名为独立测试或用作最后确认。

`natural_dev.jsonl` 由本项目从初始状态运行后收集，每任务固定取第一个模型自产工具失败。
目前配置仍使用原开发任务世界；收集后要保留source manifest、模型、条件和完整重放动作。
不要把step1的“注入错误后模型产生的新错误”混作从零收集的自然失败。

独立确认文件 `confirm_frozen.jsonl` 尚未创建。生成规则/提示冻结后，再选择新的任务世界与固定划分。
首次确认前登记任务数、主体模型、失败来源、步数、停止判据和扩样规则。

环境重放和离线评测所需记录可含payload/参考动作，但监控器仅接收公开goal字符串和已执行步骤。
这些私有字段不可被用于反馈生成或测试时的候选择优。
